# Коробка

Страница, где картонная коробка падает туда, куда наклонён телефон. Её можно схватить пальцем или мышью и бросить.

Без датчика (компьютер) тяжесть направлена вниз. На iPhone нужно нажать «Включить гироскоп» и разрешить доступ к движению: Safari иначе не отдаёт датчик. Датчик работает только по HTTPS, поэтому открывать с телефона нужно через GitHub Pages, а не как локальный файл.

## Запуск

Один файл `index.html`, без сборки и зависимостей. Локально:

```bash
python3 -m http.server 8000
```

и открыть http://localhost:8000.
